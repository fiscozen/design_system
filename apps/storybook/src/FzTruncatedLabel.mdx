# FzTruncatedLabel

A field label kept on one line. When the label is wider than the field it is cut with an ellipsis, and the full text shows in a tooltip on hover and while the labelled control has focus. Fields laid side by side stay aligned whatever their labels' length.

`FzInput`, `FzSelect` and `FzTextarea` render it for you with their `truncateLabel` prop (`FzDatepicker` through `inputProps`). Use it directly only to build a field of your own.

## Features

- One-line label, cut with an ellipsis only when it does not fit
- Full label in a tooltip on hover and while the control has focus
- An uncut label never widens the field: fields side by side share a row equally
- Required asterisk outside the cut, always visible
- The control keeps the full label as its accessible name

## Installation

```bash
npm install @fiscozen/tooltip
```

## Basic Usage

```vue
<script setup>
import { FzTruncatedLabel } from '@fiscozen/tooltip'
</script>

<template>
  <div class="flex flex-col gap-8">
    <FzTruncatedLabel
      class="text-base text-grey-500"
      label="Data di versamento dell’imposta sostitutiva"
      labelId="payment-date-label"
      controlId="payment-date"
      required
    />
    <input id="payment-date" aria-labelledby="payment-date-label" required />
  </div>
</template>
```

## Styling

Put text styles (color, size, weight) on the component: the label, the ellipsis and the asterisk inherit them.

## Accessibility

- The `<label>` holds the full text, so screen readers announce the whole label as the control's name, cut or not.
- Keyboard users see the full label in the tooltip as soon as they tab into the control; `Escape` hides it without moving focus.
- The tooltip only repeats the label: it adds no tab stop and is not announced as a description.
- The asterisk is visual only: set `required` or `aria-required` on the control.

## Best Practices

- Use it where fields share a row and their labels may wrap; a field alone on its row can let its label wrap.
- Keep labels short anyway: the tooltip is a fallback, not a place for instructions.
- Give the field a width (for example `flex-1`): the label is cut at the field's width.
